Docker入门笔记

Docker 是目前最流行的容器化引擎，可以将应用程序及其依赖打包成独立镜像，实现一次打包，到处运行。

✅ 核心概念

  • 镜像 Image：只读模板，用来创建容器
  • 容器 Container：镜像运行出来的可读写实例
  • 仓库 Registry：存放镜像的仓库，例如 Docker Hub

✅ 常用命令

docker pull nginx
docker run -d -p 80:80 nginx
docker ps
docker stop 容器ID
